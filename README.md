# DSA Lab — C Programming Coursework

A collection of Data Structures and Algorithms laboratory programs written in C. The repository is organized by topic. Each source file begins with a short `Question:` comment describing the problem it addresses.

## Repository structure

- `01_Basic_Arrays_and_Structures/` — 13 C programs
- `02_Searching_and_Sorting/` — 6 C programs
- `03_Sparse_Matrices/` — 5 C programs
- `04_Stacks/` — 4 C programs
- `05_Queues/` — 2 C programs
- `06_Linked_Lists/` — 12 C programs
- `07_Trees/` — 2 C programs
- `08_Additional_List_and_Sorting_Programs/` — 6 C programs

## Topics covered

- Arrays, basic operations, structures, and matrices
- Searching and sorting algorithms
- Sparse matrix and triplet representation
- Stacks and expression processing
- Linear and circular queues
- Singly, doubly, and circular linked lists
- Binary trees and binary search trees
- Additional linked-list exercises and Quick Sort
